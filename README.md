# Дороги и базы — пошаговая стратегия на HTML5/Canvas

> Браузерная стратегия в жанре «построй базу, захвати территорию, уничтожь врага».  
> Игра полностью на клиенте, не требует сервера. Управление — мышью, 3 действия за ход.

## ✨ Особенности

- **Пошаговая тактика** — 3 действия на ход: строительство, перемещение отрядов, атака, захват ресурсов.
- **Расширение территории** — дороги строятся за 1💰 рядом с существующими базами или дорогами.
- **Здания**:
  - 🏰 База — приносит доход каждые 3 хода, даёт территорию.
  - 🏛️ Казарма — лимитирует количество отрядов.
  - 🪵 Лесопилка, ⛏️ Шахта — пассивный доход ресурсами.
  - 🧱 Стена — защищает отряд на клетке (атакующий погибает, защитник остаётся).
  - 🏪 Рынок — обмен дерева или металла на золото.
- **Отряды** — перемещаются на соседнюю клетку (1 действие, +1💰 если на вражескую территорию). Атака уничтожает врага без стены, оба отряда погибают.
- **Ресурсы на карте** — лес (+1🪵), металл (+1⛏️), золотая жила (+20💰), житель (+1👥). Захват стоит 1💰.
- **Подсветка возможных ходов** — при выборе отряда соседние доступные клетки подсвечиваются золотистым.
- **Звуки** — эффекты для кликов, строительства, атаки, победы (можно отключить в меню).
- **Автосохранение** и ручное сохранение/загрузка (LocalStorage).
- **Адаптивный интерфейс** — работает на ПК и мобильных устройствах.

## 🎯 Цель

Уничтожить все базы противника.  
Синий и Красный игроки ходят по очереди. Победа засчитывается, когда у врага не осталось ни одной базы.

## 🕹️ Управление

- Клик по любой клетке вызывает меню доступных действий (построить дорогу, здание, нанять отряд, выбрать отряд).
- Если выбран отряд, клик по соседней клетке перемещает его или атакует.
- Завершить ход — кнопка «✅ Завершить ход».
- Бургер-меню (☰) в правом верхнем углу: сохранить/загрузить, новая игра, вкл/выкл звука, правила.

## 🧠 Правила (кратко)

- Дороги строятся только рядом с уже принадлежащей вам клеткой.
- Казармы определяют лимит отрядов (1 казарма = 1 отряд).
- Стена работает только если на клетке есть свой отряд — тогда враг погибает, ваш отряд остаётся.
- База без защитника может быть захвачена врагом, просто зашедшим на неё отрядом.
- Доход от баз начисляется каждые 3 глобальных хода (по 1💰 за базу).
- Ресурсы (лес, металл, золото, жители) дают бонус при захвате за 1💰.

## 🛠️ Технологии

- Чистый **JavaScript** (ES6)
- **Canvas** для отрисовки карты и анимаций
- **Web Audio API** для звуков
- **LocalStorage** для сохранений
- Адаптивная вёрстка без внешних зависимостей

## 🚀 Как запустить

Скачайте файл `Roads and bases — strategy.html` и откройте в любом современном браузере.  
Работает офлайн, интернет не требуется.
